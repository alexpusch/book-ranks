# Documentation guidance

- Read [DOCS.md](./DOCS.md) when a task depends on the app's purpose, behavior, architecture, or scope.
- Consult [README.md](./README.md) when setup, commands, or detailed usage are relevant. Verify implementation details against the relevant source files.
- Update [DOCS.md](./DOCS.md) when a change affects the documented purpose, behavior, architecture, or scope. Keep it short and describe implemented behavior, not planned features.
- Update [README.md](./README.md) when setup, commands, or usage change. Keep both documents consistent and avoid duplicating detailed instructions in this file.
